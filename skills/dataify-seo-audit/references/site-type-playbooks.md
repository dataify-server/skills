# Site-type playbooks

- SaaS: pricing/product/docs coverage, feature intent, canonical consistency across campaign pages.
- E-commerce: Product/Breadcrumb JSON-LD, category/product pagination, variants and availability metadata.
- Publisher/blog: Article metadata, author/date, archive pagination and topic internal links.
- Local business: LocalBusiness schema, address/phone consistency and location landing pages.
- Multilingual: reciprocal hreflang, x-default, localized canonicals and language URL consistency.

Apply only playbooks supported by visible evidence or user context.
