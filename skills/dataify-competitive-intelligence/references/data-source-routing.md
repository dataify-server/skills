# Data Source Routing

Choose sources by claim type, not by how many tools are available.

| Evidence needed | Preferred source | Dataify route | Typical use |
|---|---|---|---|
| Positioning and product claims | Official site and documentation | SERP discovery, then Web Unlocker | Snapshot, product comparison |
| Public price, limits, and units | Official pricing and billing docs | SERP discovery, then Web Unlocker | Pricing intelligence |
| Recent announcements | Official newsroom plus current news results | Google News or Bing News | Changes and momentum |
| Company and funding profile | Company site and structured company source | Crunchbase scraper when a URL is known | Company snapshot |
| Hiring signals | Official careers page and job results | Google Jobs, Indeed, or Web Unlocker | Investment themes |
| Customer feedback | Relevant review, marketplace, forum, or social source | Matching scraper or SERP skill | Review intelligence |
| Developer activity | Official documentation and repository | GitHub repository scraper and Web Unlocker | Developer experience |
| Category discovery | Search results across several query formulations | Google, Bing, or DuckDuckGo search | Market landscape |

## Minimum Plans

- Snapshot: official homepage, product/docs page, pricing page, and one current external source.
- Product comparison: equivalent official product and documentation pages for every vendor.
- Pricing: official price source for every vendor plus one normalized workload calculation.
- Reviews: enough records to identify repeated themes; report sample size, period, and source bias.
- Hiring: current role inventory grouped by function, geography, and seniority.
- Landscape: multiple discovery queries followed by first-party verification of shortlisted vendors.
- Battlecard: product, pricing, proof, objections, and current change evidence.

Start with 3–8 focused collection actions. Expand only when a material claim remains unresolved or sources conflict. Avoid collecting the same page through multiple tools unless it is needed for validation.
